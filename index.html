数据与隐私

词库保存在本浏览器的本地存储中，不会自动上传到云端。词典查询会向外部词典服务发送你输入的单词。AI 功能目前采用可选接入设计，本页面不会要求你输入或暴露 API 密钥。

AI 增强功能（后续接入）

建议通过安全的后端代理调用 AI：生成词根分析、故事记忆、雅思/商务应用，并对六级语料库中的真实句子做语境分析。不要将私密 API Key 直接写进公开网页。

当前版本的记忆提示与例句为规则生成的学习辅助内容；真题检索会提供外部搜索入口，不会把未经核实的内容标成真实真题。
